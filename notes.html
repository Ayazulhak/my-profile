Performance
Verified

Why XML parsing inside inner loops gets expensive, and what to move out

A third-party integration re-parsed the same XML document and fetched broad datasets on every iteration. The fix was not a faster parser. It was moving invariant parsing out of the hot path and narrowing each retrieval to the data the operation needed.

// before: parsed on every item
foreach (var item in items)
{
    var doc = XDocument.Parse(config);     // invariant
    var all = repo.GetAll();               // broad fetch
    Apply(item, doc, all);
}

// after: parse once, fetch by key
var doc = XDocument.Parse(config);
foreach (var item in items)
    Apply(item, doc, repo.GetByKey(item.Key));
